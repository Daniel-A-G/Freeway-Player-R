Freeway Player

Tu música, en orden. Reproductor local para Linux con listas, YouTube, podcasts, edición de metadatos y conversión de audio.

⬇ Instalar ahora Ver releases

Funciones

Todo lo que necesitas para organizar, descubrir y disfrutar tu música.

🎵

Listas con pestañas

Crea, renombra y organiza múltiples listas de reproducción. Cambia entre ellas con pestañas y persiste todo automáticamente.

▶️

YouTube integrado

Busca en YouTube, reproduce audio en streaming y descarga pistas en Opus cuando quieras guardarlas. Los resultados muestran los títulos originales.

🎙️

Podcasts

Descubre podcasts, suscríbete por URL RSS/Atom y escucha episodios con progreso guardado, estado de escuchado y carátulas. Todo se mantiene en tu equipo.

🖼️

Editor de carátulas

Añade o reemplaza la carátula de cualquier pista. Soporta PNG, JPEG y WebP (conversión automática a PNG para metadatos).

✏️

Edición de metadatos

Edita título, artista, álbum, género y número de pista directamente desde el programa. Lectura y escritura con Lofty.

🛠️

Reparación de metadatos

Si un archivo no permite guardar metadatos, Freeway puede repararlo con FFmpeg. Incluye un modo agresivo opcional cuando la reparación normal no basta.

🎚️

Conversor FLAC a Opus

Convierte archivos FLAC a Opus desde el menú Herramientas, con presets de calidad, bitrate personalizado y opciones para colisiones o reemplazo en listas.

🔀

Aleatorio y repetición

Activa la reproducción aleatoria o repite la lista actual. La configuración se guarda por lista de forma independiente.

📂

Arrastrar y soltar

Añade canciones arrastrándolas desde el gestor de archivos, suéltalas en la posición exacta de la lista e incluso reordena pistas arrastrándolas.

🔄

Actualizaciones Flatpak

El programa comprueba actualizaciones al iniciar y puede instalarlas mediante el portal Flatpak. Si hace falta intervención manual, te guía con enlaces claros.

Instalar

Freeway Player se distribuye como Flatpak. Instala desde el repositorio oficial o descarga el bundle directamente.

⬇ Instalar desde repositorio Añadir repositorio
# Añadir el repositorio e instalar
flatpak remote-add --if-not-exists freeway-player https://daniel-a-g.github.io/Freeway-Player-R/freeway-player.flatpakrepo
flatpak install freeway-player io.github.freewayplayer.FreewayPlayer

# O instalar directamente con el bundle
flatpak install --user --bundle freeway-player-*.flatpak
